# 誠得有限公司｜CHENG DE CO., LTD.

> We do what you need.

誠得是一支位於臺灣雲林虎尾的整合服務團隊，結合行銷、創意製作、程式開發與電商營運，協助品牌從策略規劃走到實際執行。

我們也把日常營運中的需求做成網站、管理後台與自動化工具，讓訂單處理、出貨與行銷工作更有效率。這個 GitHub 組織記錄了我們在這些領域的開發與實作。

[官方網站](https://tw-chengde.com/) · [關於誠得](https://tw-chengde.com/about/) · [合作洽詢](https://tw-chengde.com/contact/)

## 開發與應用

從電商後台到活動工具，我們以實際工作流程為出發點，將重複操作轉為可持續使用的系統。更多案例可參考[程式開發服務](https://tw-chengde.com/development)。

| 領域 | 應用內容 |
| --- | --- |
| 電商管理系統 | 整合 momo、mo 店+ 等多通路訂單與銷售統計，支援併單、揀貨、出貨與商品 SKU 對照。 |
| 物流與出貨工具 | 郵寄單填寫與套印、快遞叫件排程，以及例行作業自動化。 |
| 平台與通知串接 | 透過 LINE 機器人查詢訂單與營收、完成轉單及寄送出貨單，並自動寄發 LINE 禮物地址填寫提醒。 |
| 行銷與活動工具 | PTT 推文與發文排程、短連結產生、名單抽獎等操作工具。 |
| 線上實用工具 | 圖片轉 PLT、折讓單 PDF 產生、滑鼠雙擊測試、IP 查詢與公開 IG 影片下載。 |
| 品牌網站 | 建置品牌資訊、服務介紹與合作洽詢入口。 |

## 公開工具與專案

| 工具 | 功能 | 入口 |
| --- | --- | --- |
| 郵局物流單套印 | 在瀏覽器填寫郵寄資料，支援單張／整頁列印與套印位置校正。 | [線上使用](https://post-label.tw-chengde.com/) |
| 蝦皮縮網址產生器 | 將蝦皮商品網址轉為短連結，支援備註、複製與分享。 | [線上使用](https://shopeeurl.tw-chengde.com/) |
| 誠得隨機抽籤系統 | 輸入抽獎名單、自訂獎項與數量，隨機產生中獎結果。 | [線上使用](https://luckdraw.tw-chengde.com/) |
| JPG / PNG 轉 PLT | 將圖片轉為 HP-GL 向量輪廓，支援尺寸調整、路徑預覽與 PLT 下載。 | [線上使用](https://plotline.tw-chengde.com/) |
| 滑鼠雙擊連點測試 | 分別統計左鍵、中鍵與右鍵的點擊及連點次數，協助檢查異常重複點擊。 | [線上使用](https://mousedoubleclick.tw-chengde.com/) |
| 折讓單產生器 | 填寫退回或折讓資料，自動計算金額與稅額，下載二聯或四聯 A4 PDF。 | [線上使用](https://creditnote.tw-chengde.com/) |
| 我的 IP 查詢 | 自動顯示目前 IP 位址、地理位置、網路業者與時區。 | [線上使用](https://findip.tw-chengde.com/) |
| IG 影片下載 | 貼上公開 Instagram Reels 或影片貼文網址，解析並下載 MP4，支援手機與電腦瀏覽器。 | [線上使用](https://igdownload.tw-chengde.com/) |
| 便利帶自動叫件 | 透過雲端排程自動登入並呼叫快遞，依政府辦公日曆跳過放假日。 | [查看原始碼](https://github.com/tw-chengde/call-courier) |
| LINE 禮物地址填寫提醒 | 自動找出已付款但尚未填寫收件地址的訂單，以 Email 提醒送禮人並彙整每日寄送結果。 | [查看原始碼](https://github.com/tw-chengde/line-gift-pending-address) |
